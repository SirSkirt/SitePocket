  Native logger setup: Could not initialize Android native logger:
  lateinit property appId has not been initialized
Root cause CONFIRMED in repo: Rust serialized ActiveGameRequest.app_id as
"app_id" (serde default); Kotlin @InvokeArg ActiveGameArgs requires "appId".
Kotlin never persisted activeGameId; native journal events were untagged.
Rust's hook_confirmed correctly required matching appId, so it could not
accept the real native-console-hook-installed event. This was a WebCask
bridge bug, NOT a BlockBend rendering error or missing WebView hook.

PROJECT ARCHITECTURE
--------------------
- SitePocket frontend: src/main.ts, src/style.css (TypeScript, Tauri 2,
  styled dark-blue/teal interface). UI handles library, import, Game Options,
  icons, touch layouts, and debugger popups.
- Tauri Rust manager backend: src-tauri/src/lib.rs
- Shared Rust authoritative data/registry/importer:
  crates/webcask-core/src/lib.rs
  The InstalledApp registry contains per-app ID/name/kind, URL or local port,
  entry point, Game View, window mode/size, and Android touch mappings.
- Windows standalone runner:
  crates/webcask-runtime/src/main.rs (Wry/WebView2);
  src-tauri/resources/webcask-runtime.exe is packaged into installer.
  Windows game/app shortcuts launch WebCask independently of manager.
- Android player: src-tauri/src/android_player.rs
  Opens second Tauri WebViewWindow in a registered WebCaskActivity.
- Android local game server: src-tauri/src/mobile_server.rs.
  Serves extracted HTML5 content using a read-only loopback HTTP origin
  (127.0.0.1:<game-port>), with correct WASM MIME and path traversal checks.
  No need for internet for genuinely self-contained ZIP games.
- ZIP importer: crates/webcask-core/src/lib.rs; Android document staging via
  crates/tauri-plugin-android-zip-import and Kotlin ContentResolver.
- Icon handling: src-tauri/src/icons.rs; installed apps can use automatic
  favicons/bundled icons or user-supplied custom images. Windows shortcuts
  receive the selected ICO. Android icon matches the Windows SitePocket logo.
- Android native files: src-tauri/android/WebCaskActivity.kt,
  WebCaskNativeLog.kt, WebCaskSplitInitializer.kt,
  webcask_split_config.xml. Kotlin bridge:
  crates/tauri-plugin-android-zip-import/android/src/main/java/
  dev/sitepocket/zipimport/ZipImportPlugin.kt.
- Debugger Rust store: src-tauri/src/diagnostics.rs; JS game-side collection:
  src-tauri/src/android_debug.js; in-game touch controls:
  src-tauri/src/android_touch.js; manager debugger UI in src/main.ts.
- CI:
  .github/workflows/windows-release.yml
  .github/workflows/android-release.yml
  .github/scripts/setup-webcask-android.py
